# My Wallet

The back-end of a web app to register your financial transactions, both incomings and outgoings. The front-end of this app is at https://github.com/JefersonBatista/my-wallet-frontend-2.

You can send requests to it in the URL https://my-wallet-115120273090.southamerica-east1.run.app.

## About

This app includes:

- A basic sign up and login service
- Register and edition of financial transactions, both incomings and outgoings
- The final balance of the transactions
